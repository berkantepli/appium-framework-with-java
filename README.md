# Appium Framework with Java

## About the Project

This repository is a learning project focused on mobile test automation
using Java, Appium, Selenium WebDriver, and TestNG.

The project is based on practical exercises and examples from the
Udemy course
[Appium - Mobile Testing (Android/IOS) from Scratch + Frameworks](https://www.udemy.com/course/mobile-automation-using-appiumselenium-3/),
created by Rahul Shetty Academy.

The purpose of this repository is to practice mobile automation concepts,
explore different testing approaches, and strengthen my understanding
of Appium-based test automation.

## Technologies

- Java 21
- Appium
- Selenium WebDriver
- TestNG
- Maven
- Android Studio Emulator

## Topics Covered

- Android application automation
- Element identification and locators
- Explicit waits and synchronization
- Mobile gestures and scrolling
- Native application testing
- Hybrid application testing
- WebView context switching
- ChromeDriver configuration
- Mobile browser automation

## Project Status

This is an ongoing learning project. I am continuing to practice,
troubleshoot, and improve my mobile test automation skills.
